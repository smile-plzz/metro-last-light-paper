## 1. Project Overview & Repository Index

This research repository contains an exhaustive, interdisciplinary critical game studies investigation of *Metro: Last Light* (4A Games, 2013). The study analyzes how post-apocalyptic world-building, ideological factionalism, character psychology, survival mechanics, and implicit moral evaluations interrogate humanity's persistent capacity for violence and potential for redemption.
